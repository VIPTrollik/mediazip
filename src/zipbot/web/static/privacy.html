Privacy policy

Discord media downloader · last updated 2 November 2026

What this app does

When you use Download attachments, Add to ZIP basket, /basket, or send messages to the bot in a DM, the app reads the attachments (files of any type) and image/video embeds of those messages and creates a short-lived download link for you.

What is stored, and for how long

  • In memory only, never on disk: for each link — your Discord user ID, the Discord CDN addresses, file names, sizes and dimensions of the files, and a one-way hash of the link's secret. Links expire after at most 60 minutes (sooner if Discord's file links expire first) and can be revoked at any time with Revoke link.
  • Basket: the same kind of data for the messages you add, kept for 60 minutes after your last change, or until you clear it.
  • Everything is deleted when it expires or when the service restarts.

What is not stored

  • The files themselves. Your browser downloads them directly from Discord; they never pass through this server.
  • Message text. The app does not keep the content of your messages.
  • Logs of links, file names, or addresses. Server logs contain only counts and error types.

Sharing

No data is sold or shared with third parties. Anyone who has a download link can use it until it expires, so only share it if you want others to download the files.

Revoking a link (or its expiry) stops it from being opened again. Whoever already opened it has received Discord's own file addresses, which Discord keeps valid for about a day; that is the same as the file links Discord itself shows in the chat.

Contact

Questions or deletion requests: contact the operator of this instance through the bot's Discord application page. Because nothing is kept for longer than an hour, there is usually nothing left to delete.
