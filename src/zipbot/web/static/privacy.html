Privacy policy

MediaZip · last updated 4 November 2026

What this app does

When you use Download media, Add to ZIP, /zip, or send messages to the bot in a DM, the app reads the image and video attachments and embeds of those messages and creates a short-lived download link for you.

What is stored, and for how long

  • In memory only, never on disk: for each link — your Discord user ID, the Discord CDN addresses, file names, sizes and dimensions of the media, and a one-way hash of the link's secret. Links expire after at most 60 minutes (sooner if Discord's file links expire first) and can be revoked at any time with Revoke link.
  • Your ZIP (Add to ZIP): the same kind of data for the messages you add, kept for 60 minutes after your last change, or until you clear it. The bot shows your ZIP in one message in its DM with you; clearing it deletes that message, and when it expires the message is edited to "Your ZIP expired", without links, previews or file names. A message left over from a restart is cleaned up the next time you use Add to ZIP or /zip.
  • Everything is deleted when it expires or when the service restarts.

What is not stored

  • The files themselves. Your browser downloads them directly from Discord; they never pass through this server.
  • Message text. The app does not keep the content of your messages.
  • Logs of IP addresses, links, file names or file addresses. The app's own logs contain only counts and error types, and the web server keeps no access log.

Website analytics

This site uses no analytics, no cookies and no third-party scripts.

Hosting

The site is served through Cloudflare (Cloudflare, Inc.), which sits in front of it as a reverse proxy and content delivery network. Cloudflare may process data in the United States and elsewhere.

  • Cloudflare handles the encrypted (HTTPS) connection, so every request to this site passes through it, including the download page and its API: your IP address, the addresses requested, request headers, and the content of API requests and responses. That includes a download link's secret, which the download page sends to the API, and the Discord file addresses the API returns.
  • Cloudflare does not see the files themselves: your browser downloads them directly from Discord, not through this site.
  • Behind Cloudflare, the web server (nginx) keeps no access log, and neither it nor the app logs IP addresses. To limit how often the download API can be called, the app keeps the IP addresses of up to 10,000 recent visitors, with the times of their requests in the last minute, in memory only (cleared on restart).
  • Legal basis: our legitimate interest in delivering the site and protecting it from abuse (Art. 6(1)(f) GDPR). Cloudflare's own handling of this data is described in Cloudflare's privacy policy.

Sharing

No data is sold. The only third parties involved are Discord, where the files live, and Cloudflare, which serves the site as described under Hosting. Anyone who has a download link can use it until it expires, so only share it if you want others to download the files.

Revoking a link (or its expiry) stops it from being opened again. Whoever already opened it has received Discord's own file addresses, which Discord keeps valid for about a day; that is the same as the file links Discord itself shows in the chat.

Contact

Questions or deletion requests: contact the operator of this instance through the bot's Discord application page. Because link and ZIP data is kept for an hour at most, there is usually nothing left to delete.
