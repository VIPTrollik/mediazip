Privacy policy

MediaZip · last updated 3 November 2026

What this app does

When you use Download media, Add to ZIP, /zip, or send messages to the bot in a DM, the app reads the image and video attachments and embeds of those messages and creates a short-lived download link for you.

What is stored, and for how long

  • In memory only, never on disk: for each link — your Discord user ID, the Discord CDN addresses, file names, sizes and dimensions of the media, and a one-way hash of the link's secret. Links expire after at most 60 minutes (sooner if Discord's file links expire first) and can be revoked at any time with Revoke link.
  • Your ZIP (Add to ZIP): the same kind of data for the messages you add, kept for 60 minutes after your last change, or until you clear it. The bot shows your ZIP in one message in its DM with you; clearing it deletes that message, and when it expires the message is edited to "Your ZIP expired", without links, previews or file names. A message left over from a restart is cleaned up the next time you use Add to ZIP or /zip.
  • Everything is deleted when it expires or when the service restarts.

What is not stored

  • The files themselves. Your browser downloads them directly from Discord; they never pass through this server.
  • Message text. The app does not keep the content of your messages.
  • Logs of links, file names, or addresses. Server logs contain only counts and error types.

Website analytics

The start page, this privacy policy and the terms of service use Google Analytics to count visits, in a cookieless mode: consent for analytics and advertising storage is set to "denied" before Google's script loads, so no cookies or similar identifiers are stored on your device and no advertising features are used.

  • Google receives the page viewed (its address without anything after the path), the time, coarse device and browser information (such as browser, operating system, screen size and language), and your IP address. Google (Google Ireland Ltd. and Google LLC) processes the IP address and device data, possibly in the United States, and uses the IP address to derive an approximate region; according to Google, it is not logged or stored.
  • Legal basis: our legitimate interest in knowing how many people visit these pages and how they find them (Art. 6(1)(f) GDPR). You have the right to object to this at any time; the simplest way is to block Google Analytics in your browser, for example with a content blocker or Google's opt-out browser add-on. The app works the same either way.
  • The download pages (/d), the Discord bot and the download links never use Google Analytics. Nothing about your Discord account, messages or files is sent to Google.
  • Google's own handling of this data is described in Google's privacy policy and how Google uses information from sites that use its services.

This site uses no analytics, no cookies and no third-party scripts.

Sharing

No data is sold. Apart from the website analytics above, nothing is shared with third parties. Anyone who has a download link can use it until it expires, so only share it if you want others to download the files.

No data is sold or shared with third parties. Anyone who has a download link can use it until it expires, so only share it if you want others to download the files.

Revoking a link (or its expiry) stops it from being opened again. Whoever already opened it has received Discord's own file addresses, which Discord keeps valid for about a day; that is the same as the file links Discord itself shows in the chat.

Contact

Questions or deletion requests: contact the operator of this instance through the bot's Discord application page. Because nothing is kept for longer than an hour, there is usually nothing left to delete.
