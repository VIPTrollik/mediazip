MediaZip

Every image and video, saved or zipped.

Choose Download media on a message. MediaZip replies privately: Download all for separate files, or Download ZIP. Add more messages with Add to ZIP.

Add to Discord Add to a server

Add to Discord puts it on your account, for any server or DM. Add to a server makes it available to everyone there (needs Manage Server).

How it works

  1. Pick a message

    Right-click or long-press it, then choose Apps → Download media.

  2. Save or zip

    In the reply only you can see, tap Download all for separate files or Download ZIP for one archive.

  3. Collect more

    Use Apps → Add to ZIP on other messages, then Download your ZIP for one archive with a folder per message. Or forward them to MediaZip in a DM.

Frequently asked questions

How do I download all images from a Discord message?

Right-click the message (or long-press it on mobile), then choose Apps → Download media. MediaZip replies privately with Download all, which saves every image and video as separate files, and Download ZIP, which saves them as one ZIP.

Can I download Discord attachments as one ZIP?

Yes. Download ZIP puts every image and video of a message into one ZIP, built in your browser. To combine several messages, use Apps → Add to ZIP on each one, then Download your ZIP to get one ZIP with a folder per message. You can also forward the messages to MediaZip in a DM and get one link for all of them.

Does it work on the Discord mobile app?

Yes. Long-press a message, then choose Apps → Download media. The download page opens in your phone's browser, where it saves the files, builds a ZIP, or opens your device's share sheet if the browser supports it.

Do I need to add the bot to a server?

No. Add to Discord installs MediaZip on your account, and it then works in every server and DM, including ones where the bot isn't a member. Add to a server is optional: it makes MediaZip available to everyone in that server (needs Manage Server).

Does MediaZip store my files?

No. Your browser downloads the files directly from Discord and builds the ZIP on your device, so they never pass through MediaZip's server. The server keeps only the links (Discord's file addresses, names and sizes) in memory, never on disk, until they expire.

Why aren't PDFs and other documents included?

Discord's CDN lets browsers fetch images and videos from other sites (CORS), but not documents and other files. Without that permission the download page can't fetch them, so MediaZip saves images and videos only.

Is MediaZip free and open source?

Yes. It is free to use, and its code is on GitHub under the MIT license, so you can read it or host your own copy.

How long do download links last?

60 minutes, or less if Discord's own file links expire sooner. You can end a link earlier with the Revoke button. Until then, anyone who has the link can download those files, so share it only on purpose.

Your images and videos go straight from Discord to your device. MediaZip never stores them, keeps no file names in its logs, and download links are short-lived. How your data is handled
